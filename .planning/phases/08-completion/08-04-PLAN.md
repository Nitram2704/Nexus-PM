# 08-04: Exportar Backlog a CSV

**Phase:** 8 — Completion
**Requirement:** RPT-03
**User Stories:** HU-33
**Tipo:** Backend + Frontend

## Context

No existe exportación CSV en ninguna parte del código. Hay que crear el endpoint backend
y el botón frontend. Es el único item de Phase 7 que queda pendiente.

## Archivos existentes relevantes

- `backend/apps/projects/views.py` — `ProjectViewSet` (agregar action aquí)
- `backend/apps/tasks/models.py` — modelo `Task`
- `frontend/src/pages/BacklogPage.tsx` — donde va el botón
- `frontend/src/api/projects.ts`

## Proposed Changes

### [MODIFY] `backend/apps/projects/views.py`
Agregar action `export_csv` al `ProjectViewSet`:
```python
@action(detail=True, methods=['get'])
def export_csv(self, request, pk=None):
    project = self.get_object()
    tasks = Task.objects.filter(project=project).select_related('column', 'assignee', 'sprint')
    response = HttpResponse(content_type='text/csv')
    response['Content-Disposition'] = f'attachment; filename="{project.key}-backlog.csv"'
    writer = csv.writer(response)
    writer.writerow(['key', 'title', 'type', 'priority', 'status', 'assignee', 'story_points', 'sprint'])
    for t in tasks:
        writer.writerow([...])
    return response
```
Columnas: clave, título, tipo, prioridad, estado (columna), asignado, story points, sprint.

### [MODIFY] `frontend/src/api/projects.ts`
- `exportBacklogCsvApi(projectId)` → `GET /v1/projects/<id>/export_csv/` con `responseType: 'blob'`

### [MODIFY] `frontend/src/pages/BacklogPage.tsx`
Agregar botón "Exportar CSV" en el header del backlog que descargue el archivo.
