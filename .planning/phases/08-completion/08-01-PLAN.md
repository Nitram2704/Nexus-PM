# 08-01: UI de Gestión de Proyectos

**Phase:** 8 — Completion
**Requirement:** PRJ-01, PRJ-03, PRJ-04, PRJ-05
**User Stories:** HU-06, HU-08, HU-09, HU-10
**Tipo:** Frontend (backend ya existe)

## Context

El backend tiene `ProjectViewSet` completo (CRUD + invite + analytics). El frontend NO tiene
forma de crear, listar, editar ni archivar proyectos. Solo hay mini-cards en `DashboardPage`.
Este es el gap más crítico: sin esto, un usuario nuevo no puede usar la app.

## Archivos existentes relevantes

- `frontend/src/api/projects.ts` — solo tiene `getProjectDetailApi`, `getProjectAnalyticsApi`, `moveTaskApi`
- `frontend/src/types/project.ts` — tipos `Project`, `ProjectAnalytics`
- `frontend/src/pages/DashboardPage.tsx` — muestra proyectos vía `getDashboardDataApi`
- `frontend/src/App.tsx` — rutas actuales
- `frontend/src/components/Modal.tsx` — modal reutilizable
- `frontend/src/components/layout/MainLayout.tsx` — layout con Navbar

## Proposed Changes

### [MODIFY] `frontend/src/api/projects.ts`
Agregar funciones faltantes:
- `listProjectsApi()` → `GET /v1/projects/`
- `createProjectApi(data)` → `POST /v1/projects/`
- `updateProjectApi(id, data)` → `PATCH /v1/projects/<id>/`
- `archiveProjectApi(id)` → `PATCH /v1/projects/<id>/` con `is_archived: true`

### [NEW] `frontend/src/pages/ProjectsPage.tsx`
Página de listado de proyectos:
- Grid de cards con nombre, key, # miembros, última actividad
- Botón "Nuevo Proyecto" que abre modal de creación
- Filtro: todos / activos / archivados
- Cada card: acciones abrir (→ kanban), editar, archivar/restaurar
- Empty state diseñado cuando no hay proyectos (UIX-04)

### [NEW] `frontend/src/components/projects/ProjectFormModal.tsx`
Modal para crear/editar proyecto:
- Campos: nombre (requerido, max 100), descripción (opcional, max 500), clave (auto-generada del nombre, editable)
- Validación de campos
- Modo create vs edit

### [MODIFY] `frontend/src/App.tsx`
Agregar ruta `/projects` dentro de `ProtectedRoute` + `MainLayout`.

### [MODIFY] `frontend/src/components/layout/Navbar.tsx`
Agregar link a `/projects` en la navegación.

### [MODIFY] `frontend/src/pages/DashboardPage.tsx`
Agregar botón/link "Ver todos los proyectos" que navegue a `/projects`.

## Notes
- La clave (`key`) es REQUERIDA por `ProjectSerializer` — el frontend debe auto-generarla del nombre (ej: "Nexus" → "NEX", primeras 3 letras uppercase) y enviarla. El backend la uppercasea vía `validate_key`.
- `ProjectDetailSerializer` incluye `members` y `columns` — útil para la vista de detalle.
- Seguir la estética "Tactical Midnight" (ver `index.css`): dark bg, cyan accent, zero border-radius, JetBrains Mono para labels.
