# 08-03: UI de Perfil de Usuario

**Phase:** 8 — Completion
**Requirement:** AUTH-04
**User Stories:** HU-04
**Tipo:** Frontend + pequeño ajuste backend

## Context

El modelo `User` tiene `first_name`, `last_name`, `bio`, `avatar` (URLField). Existe `GET /auth/me/`
pero NO hay endpoint para actualizar el perfil ni UI para editarlo.

## Archivos existentes relevantes

- `backend/apps/accounts/views.py` — `MeView` (solo GET)
- `backend/apps/accounts/serializers.py` — `UserSerializer`
- `backend/apps/accounts/urls.py` — rutas de auth
- `frontend/src/store/authStore.ts` — `useAuthStore` con `user`
- `frontend/src/api/auth.ts` — `getMeApi`
- `frontend/src/components/layout/Navbar.tsx` — probablemente muestra el usuario

## Proposed Changes

### [MODIFY] `backend/apps/accounts/views.py`
Agregar método `PATCH` a `MeView` para actualizar `first_name`, `last_name`, `bio`, `avatar`.

### [MODIFY] `backend/apps/accounts/serializers.py`
Asegurar que `UserSerializer` permita escritura de `first_name`, `last_name`, `bio`, `avatar`.

### [MODIFY] `frontend/src/api/auth.ts`
- `updateProfileApi(data)` → `PATCH /auth/me/`

### [NEW] `frontend/src/components/ProfileModal.tsx` o página de settings
- Campos: nombre, apellido, bio, avatar URL
- Guardar actualiza el store de auth
- Accesible desde el Navbar (click en avatar/nombre de usuario)

### [MODIFY] `frontend/src/store/authStore.ts`
Agregar acción `updateUser(user)` para actualizar el usuario tras guardar el perfil.
