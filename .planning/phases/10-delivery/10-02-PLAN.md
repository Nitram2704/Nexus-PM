# 10-02: CI/CD con GitHub Actions

**Phase:** 10 — Delivery
**Tipo:** DevOps

## Context

No hay ningún workflow de CI. Hay que agregar uno que corra lint, typecheck y tests en cada PR.

## Proposed Changes

### [NEW] `.github/workflows/ci.yml`
Workflow que en cada PR:
1. **Backend:** setup Python, instalar deps, `python manage.py check`, `python manage.py test`
2. **Frontend:** setup Node, `npm ci`, `npm run lint`, `npm run build`

## Task Breakdown
- [ ] T1: Crear `.github/workflows/ci.yml`
- [ ] T2: Job de backend (Python 3.10+, SQLite, sin GOOGLE_API_KEY para usar mock)
- [ ] T3: Job de frontend (Node 18+, lint + build)
- [ ] T4: Verificar que pase en un PR de prueba

## Verification
- El workflow corre en verde en un PR
- Fallos de lint/test bloquean el merge

## Notes
- Backend usa SQLite en CI (sin DB_HOST). No configurar PostgreSQL para simplificar.
- Sin GOOGLE_API_KEY → intelligence cae a mock, los tests no dependen de la API real.
