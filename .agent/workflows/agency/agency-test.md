# /agency-test

An multi-perspective audit to ensure the application meets "Gold Standard" performance and quality.

## 🔴 Reality Check
`agency-testing-reality-checker` audits the logic and UX consistency.
- Any "fake" or shallow features?
- Does the flow make actual sense for a human?

## ♿ Accessibility Scan
`agency-testing-accessibility-auditor` verifies WCAG 2.1 compliance.
- Contrast ratios, ARIA labels, keyboard navigation.

## ⚡ Performance Benchmarking
`agency-testing-performance-benchmarker` profiles the code.
- Core Web Vitals (LCP, FID, CLS).
- Bundle size & optimization audit.

---
**Usage**: Mandatory before any git push or deployment.
