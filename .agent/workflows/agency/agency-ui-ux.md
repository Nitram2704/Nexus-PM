# /agency-ui-ux

A specialized design sprint to create unforgettable and high-performance interfaces.

## Step 1: User Experience Foundation 📐
Activate `agency-design-ux-architect`.
- Analyze user flows and content hierarchy.
- Propose a layout that avoids clichés (no standard split-screens).

## Step 2: Visual High-Fidelity 🎨
Activate `agency-design-ui-designer`.
- Apply the "Tactical OS" theme (Midnight Void & Cyan).
- Ensure pixel-perfect component architecture.

## Step 3: Polish & "Magic" ✨
Activate `agency-design-whimsy-injector`.
- Add meaningful micro-interactions and transitions.
- Ensure the interface feels "alive" and premium.

---
**Usage**: Call this command when redesigning a view or creating a new dashboard module.
