# /agency-delivery

This workflow orchestrates a high-precision delivery cycle using the most senior Agency specialists.

## Phase 1: Product Specification 📝
Invoke `agency-product-manager` to:
- Refine the user requirements into a formal specification.
- Create a `REQUIREMENTS.md` artifact if it doesn't exist.

## Phase 2: Technical & UX Architecture 📐
Invoke `agency-design-ux-architect` to:
- Define the layout structure and CSS foundation.
- Establish the information architecture.

## Phase 3: Visual Design System 🎨
Invoke `agency-design-ui-designer` to:
- Apply the visual palette and component styles.
- Ensure the design feels premium and matches the "Tactical OS" spirit.

## Phase 4: Engineering Implementation 💻
Invoke `agency-engineering-frontend-developer` (or `backend-architect`) to:
- Implement the code following the architectural guidelines.
- Ensure high performance and clean code standards.

## Phase 5: Reality Audit 🔍
Invoke `agency-testing-reality-checker` to:
- Conduct an aggressive sanity check.
- Identify gaps or logic errors before final delivery.

---
**Usage**: Start this workflow whenever building a complex feature from scratch.
